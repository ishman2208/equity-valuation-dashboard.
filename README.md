# Financial Valuation Dashboard

Enter a ticker, get `<TICKER>_Financial_Valuation.xlsx` (Dashboard, DCF, CCA, Financials, Sensitivity).

**Local:** `pip install -r requirements.txt` then `python main.py`
**Google Colab:** paste `main.py` into one cell and run it. Packages install automatically and the .xlsx downloads at the end.

Tip: auto-selected peers come from Yahoo's industry/sector lists and can be weak. At the peer prompt you can type your own, e.g. `RIO, VALE, FCX`.
